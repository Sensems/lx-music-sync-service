# 听柜 UI 文案与主题

日期：2026-09-14  
状态：已批准

## 目标

1. 文案改为轻音乐感、说人话（方案 B），产品名保留「听柜」
2. 「歌曲墙」统一改为「唱片墙」
3. 默认柔和暗色（比旧主题更亮），设置里可切换 4 套主题，偏好存 localStorage

## 导航与常用词

| 旧 | 新 |
|----|----|
| 歌单墙 | 歌单 |
| 歌曲墙 | 唱片墙 |
| 找歌 | 搜索 |
| 任务带 | 任务 |
| 柜门 | 设置 |
| 压盘 | 同步（歌单）/ 下载（单曲） |
| 压进磁盘 | 下载到本地 |
| 在柜 / 待压 | 已下载 / 未下载 |

## 主题预设

1. `nightwood` 夜木（默认）— 暖暗、更亮一档
2. `paper` 纸白 — 浅色暖灰
3. `slate` 青石 — 冷灰蓝暗色
4. `pine` 松绿 — 深松绿 + 浅金点缀

实现：CSS 变量驱动页面 + Ant Design `ConfigProvider` token；`localStorage` 键 `tingui-theme`。

## 非目标

- 不把主题写入服务端设置
- 不改后端 API / 路由 path（`/wall` 等可保留）
