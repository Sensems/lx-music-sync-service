# 歌词滚动组件

日期：2026-09-20  
状态：待审

## 目标

1. 把全屏页里三处重复的歌词列表抽成一个组件。
2. 手滑歌词时高亮中线那一行，旁侧给出带时间的播放按钮；点了就从那一句起播。
3. 滑完两秒内没点播放，列表回到正在播的那一行。
4. 桌面和手机都要；车载不接。

## 非目标

- 车载仍用 `PlayerShell` 里现有的五行大字，不改交互。
- 不做逐字卡拉 OK、翻译歌词对照、歌词内搜索。
- 不改 LRC 解析（`web/src/player/lyrics.ts`）和 `/api/lyrics`。
- 不持久化预览位置；换歌或离开全屏即清掉。
- 不新增前端单测；用 `npm --prefix web run build` 做类型检查。

## 结构

新增 `web/src/player/LyricScroller.vue`。`NowView` 桌面右侧、手机封面预览、手机整页歌词三处都换成它。

组件入参：

| 入参 | 含义 |
| --- | --- |
| `lines` | 已解析的歌词行（`LyricLine[]`） |
| `activeIndex` | 当前播放到第几行（`usePlayer.lyricIndex`） |
| `variant` | `desk` / `preview` / `full`，只改字号和内边距 |
| `active` | 这列歌词是否在眼前。`false` 时清掉预览和计时，只保留跟唱。默认 `true` |
| 点播放 | 回调该行的 `time`，由页面转给 `usePlayer.seek`；若暂停则一并开播 |

`usePlayer` 继续负责：拉词、解析 LRC、按进度算 `lyricIndex`、真正 `seek`。组件只负责画行、跟唱滚动、手滑预览、两秒回位。

```
usePlayer          NowView（桌面 / 手机封面 / 手机整页）
lyricLines ──────► LyricScroller
lyricIndex ──────►   跟唱 / 预览高亮
seek ◄────────────   点播放按钮
                   PlayerShell 车载：不经过这里
```

换歌时预览状态清掉，直接跟新歌进度。

## 跟唱、手滑、回位

默认是**跟唱**：高亮 `activeIndex` 那一行，列表把它滚到竖向中线。这时不显示播放按钮。

手一开始滚（滚轮、触摸、拖滚动条），进入**预览**：

- 跟唱停下，不再跟 `lyricIndex` 抢滚动。
- 高亮改成离中线最近的那一行。
- 这一行右侧出现播放按钮，上面写这行的时间（如 `02:51`）。
- 组件自己滚出来的位移不当成手滑，避免跟唱把自己踢进预览。

松手后开始计两秒；中途又滚，计时重来。两秒内没点播放：列表平滑滚回正在播的那一行，预览取消，回到跟唱。播放进度本身不变。

点播放：`seek` 到这一行的时间；若暂停着，一并开始播。立刻退出预览、回到跟唱。

换歌（`lines` 换成另一首）、`active` 变为 `false`、或组件卸载：预览清掉，计时取消。NowView 在离开歌词页、收起全屏、进入车载时把对应实例的 `active` 关掉或直接卸载。进度条、上一首 / 下一首不进预览；若当时已在预览，两秒到了仍滚回此时正在播的那一行。

`prefers-reduced-motion` 时不平滑滚，直接跳到目标行。空行只要有时间戳，也能预览、能点。时间写成 `mm:ss`，不足十分钟也补零（`02:51`）。

手机左右滑封面/歌词仍由 `NowView` 处理；歌词区域只吃上下滑，不跟左右滑抢。

## 外观

沿用现在全屏页的词：居中、上下淡出、当前行更大更亮。不另做皮肤，颜色用现有 `--fg` / `--mute` / `--foil`。

跟唱时只有字号和颜色变化。预览时，离中线那一行用同一套高亮，右侧多一颗小胶囊按钮：播放三角 + `mm:ss`。词仍居中，按钮绝对贴在列表右缘、和该行垂直对齐，不把句子挤歪。

```
        有些事情你现在不问
        有些人你永远不必等
     早知道伤心总是难免的     ▶ 02:51
        你又何苦一往情深
```

三种尺寸只改疏密，交互一样：

- `desk`：桌面右侧，现有大字
- `preview`：手机封面页底下那截，略紧
- `full`：手机整页歌词

只有按钮能跳进度，点句子本身不跳，免得滑着用的时候误触。按钮 `aria-label` 为「从 mm:ss 播放」。同一时刻只高亮一行：预览时是中线那行，跟唱时是正在播的那行。

## 空态与失败

- 没有歌词，或解析结果为空：显示「暂无歌词」，没有可点的行，也不进预览。
- 拉词失败仍由 `NowView` 顶上那句人话报错，组件不管。
- 点播放后若 `seek` 或开播失败，沿用播放器现有提示（「暂时没有可播放的地址」）。歌词列表回到跟唱，不停在预览。

## 验收

桌面全屏、手机封面预览、手机整页歌词都要能：跟唱、手滑出按钮、点播跳转、两秒回位。换歌后预览必须清掉。车载外观与操作与现在一致。
