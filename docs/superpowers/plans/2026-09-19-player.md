# 听柜播放器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 去掉唱片墙歌词抽屉，并加上四种形态的全局播放器：本地文件优先、否则音源试听；支持只播一首、播放当前歌单、加入队列。

**Architecture:** 后端 `createStreamService` 解析 songKey / musicInfo，有本地文件就 Range 输出，否则 `getMusicUrl` 后由服务端转发。HTML `<audio>` 只请求 `GET /api/stream?songKey=`；`POST /api/stream` 把未入库的 `musicInfo` 记进内存后再用同一 GET。前端一个 `usePlayer` 单例 + `PlayerShell.vue` 按 `bar | full | car` 和窄屏 CSS 换形态。队列算法是无 Vue 的纯函数，用根目录 Vitest 测。

**Tech Stack:** Hono、better-sqlite3、Vue 3、原生 HTMLAudioElement、Vitest、现有音源 `runtime.getMusicUrl`。

## Global Constraints

- ESM + NodeNext：相对 import 必须带 `.js` 后缀。
- 只能单进程；不要 cluster / 多实例。
- 默认 host 仍是 `127.0.0.1`，不要改成 `0.0.0.0`。
- 音源沙箱不暴露 `fs` / `process` / 真实 `require`。
- 同步语义不变：不因播放删除本地文件。
- UI 文案用短词：播放、加入队列、播放歌单、车载、返回；失败用「暂时没有可播放的地址」。
- `localStorage` 键 `tingui-player` 只存音量、循环、随机；不存队列和进度；刷新不自动续播。
- `<audio src>` 只指向本服务 `/api/stream...`，不把音源直链写进页面。
- 测试不打真实平台；HTTP 用 `createApp(ctx)` + `app.request`。
- 改行为就补 `test/<模块>.test.ts`；前端改动跑 `npm --prefix web run build`。

```ts
export type StreamDeps = {
  repos: Repos
  getMusicUrl: (
    source: string,
    musicInfo: MusicInfo,
    quality: Quality,
  ) => Promise<{ type: Quality; url: string }>
  getWantedQuality: () => Quality
  fetchRemote?: (url: string, headers: Record<string, string>) => Promise<{
    status: number
    headers: Headers
    body: ReadableStream<Uint8Array> | null
  }>
}

export function createStreamService(deps: StreamDeps): {
  remember(musicInfo: MusicInfo): void
  resolveMusicInfo(songKey: string): MusicInfo | null
  open(songKey: string, rangeHeader: string | undefined): Promise<Response>
}
```

`open`：本地文件存在 → `200`/`206` 文件流；否则 `getMusicUrl` + `fetchRemote`（默认 `fetch`）转发，非法 URL → status 502 JSON `{ error: '暂时没有可播放的地址' }`。

POST `/api/stream` JSON `{ musicInfo }` → `remember` 后 `{ songKey: musicInfo.id }`。  
GET `/api/stream?songKey=` → `open`。

`src/services/stream.ts` 要点：

- `remember`：`Map<string, MusicInfo>`，键为 `musicInfo.id`。
- `resolveMusicInfo(songKey)`：先 Map，再 `downloads.get` 解析 `raw`，再 `tracks.findBySongKey` 解析 `raw`。
- 本地：`existsSync(file_path)` 则 `stat` + 解析 `Range: bytes=start-end`，`createReadStream` 包成 `Response`，`Accept-Ranges: bytes`，`Content-Type` 按扩展名（`.mp3` → `audio/mpeg`，`.flac` → `audio/flac`，否则 `application/octet-stream`）。
- 远端：`wanted = getWantedQuality()`，`sourceQualities` 从 `getMusicUrl` 调用侧用 `[wanted]` 即可（与 sync 一样可再 `pickQuality`：`pickQuality(wanted, [wanted, '320k', '128k'], songQualitiesFromMeta)`，`songQualities` 来自 `musicInfo.meta._qualitys` 若存在否则 `{ [wanted]: true }`）。URL 必须 `^https?:`。`fetchRemote(url, { Range })`。把远端 status/headers 里的 `Content-Type`、`Content-Range`、`Content-Length` 拷到 Response。
- `getMusicUrl` 抛错或空 url：502 `{ error: '暂时没有可播放的地址' }`。
- 找不到 musicInfo：404 `{ error: 'not found' }`。

```ts
async function lyricPayload(songKey: string, musicInfo: MusicInfo) {
  try {
    const { getLyricForMusic } = await import('../services/lyrics.js')
    const lyric = await getLyricForMusic(musicInfo)
    return {
      songKey,
      name: musicInfo.name,
      singer: musicInfo.singer,
      source: musicInfo.source,
      picUrl: String(musicInfo.meta?.picUrl || ''),
      lyric: lyric.lyric || '',
      tlyric: lyric.tlyric || '',
    }
  } catch {
    return {
      songKey,
      name: musicInfo.name,
      singer: musicInfo.singer,
      source: musicInfo.source,
      picUrl: String(musicInfo.meta?.picUrl || ''),
      lyric: '',
      tlyric: '',

app.post('/api/lyrics', async c => {
  const body = await readJson(c)
  let musicInfo = asMusicInfo(body)
  const songKey = typeof body.songKey === 'string' ? body.songKey : musicInfo?.id
  if (!musicInfo && typeof body.songKey === 'string') {
    const row = repos.downloads.get(body.songKey)
    const track = repos.tracks.findBySongKey(body.songKey)
    const raw = row?.raw || track?.raw || '{}'
    try {
      musicInfo = JSON.parse(raw) as MusicInfo
    } catch {
      musicInfo = null
    }
  }
```

```ts
// types.ts
export type PlayItem = {
  songKey: string
  name: string
  singer: string
  picUrl: string
  source: string
  musicInfo: {
    id: string
    name: string
    singer: string
    source: string
    interval: number | null
    meta: Record<string, unknown>
  } | null
}

export type LoopMode = 'off' | 'one' | 'all'

export type QueueState = {
  items: PlayItem[]
  index: number
}

export type LyricLine = { time: number; text: string }
```

```ts
// queue.ts
export function playOne(item: PlayItem): QueueState
export function playList(items: PlayItem[]): QueueState
export function enqueue(state: QueueState, item: PlayItem): { state: QueueState; added: boolean; started: boolean }
export function removeAt(state: QueueState, index: number): QueueState
export function jumpTo(state: QueueState, index: number): QueueState
export function nextIndex(state: QueueState, loop: LoopMode, shuffle: boolean, rng?: () => number): number | null
export function prevIndex(state: QueueState, loop: LoopMode): number | null
```

`enqueue`：`items.some(i => i.songKey === item.songKey)` → `{ added: false, started: false }`；空队列 → items `[item]` index 0、`started: true`；否则 append、`started: false`。

`nextIndex`：`loop === 'one'` 返回当前 index；到末尾且 `off` 返回 `null`；`all` 回到 0。`shuffle === true` 且长度 > 1 时，下一首在**其余下标**里用 `rng()`（默认 `Math.random`）挑一个，不要当前 index。

`playList([])` 返回 `{ items: [], index: 0 }`。

```ts
// lyrics.ts
export function parseLrc(raw: string): LyricLine[]
export function activeLineIndex(lines: LyricLine[], t: number): number
```

`parseLrc` 认 `[mm:ss.xx]` / `[mm:ss]`；同一时间多行拼成一行用 `/` 或保留多条（保留多条即可）。忽略无时间戳的行。`activeLineIndex`：最后一个 `time <= t` 的下标，没有则 0，空数组 -1。

```ts
rememberStream: (musicInfo: unknown) =>
  fetch('/api/stream', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ musicInfo }),
  }).then(async r => {
    const body = await r.json()
    if (!r.ok) throw new Error(body.error || '暂时没有可播放的地址')
    return body as { songKey: string }
  }),
streamUrl: (songKey: string) => `/api/stream?songKey=${encodeURIComponent(songKey)}`,
lyricsFor: (input: { songKey?: string; musicInfo?: unknown }) =>
  fetch('/api/lyrics', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(input.musicInfo ? { musicInfo: input.musicInfo } : { songKey: input.songKey }),
  }).then(async r => {
    const body = await r.json()
    if (!r.ok) throw new Error(body.error || '歌词获取失败')
    return body as { lyric: string; tlyric?: string }
  }),
```
